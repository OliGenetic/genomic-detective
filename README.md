# Поиск генетических причин редких наследственных вариантов

**Команда:** OMIX
**Хакатон:** Синтез
**Дата:** 12.11.2026

## О проекте
Наша система предназначена для решения задачи поиска молекулярной причины редкого наследственного заболевания. На вход система получает клиническое описание пациента (в формате Phenopacket/HPO) и файл генетических вариантов (VCF/TSV). На выходе мы предоставляем ранжированный список генов-кандидатов с полным объяснением, почему система выбрала именно их.

## Архитектура пайплайна
Наш пайплайн состоит из четырех последовательных этапов:

1. **Загрузка данных (Loader):** Чтение сырых таблиц с вариантами (`src/loader.py`) и извлечение симптомов пациента, включая положительные и исключенные (`src/phenotype_parser.py`).
2. **Функциональная аннотация (Annotator):** Поскольку исходные данные не содержат информации о генах, мы используем REST API Ensembl VEP (GRCh38) для определения гена и типа мутации (consequence) по координатам (`src/annotate_case.py`). Запросы отправляются батчами по 200 вариантов для оптимизации времени.
3. **Скоринг (Scorer):** Наш алгоритм (`src/scorer.py`) использует базу знаний HPO (`genes_to_phenotype.txt`). Для каждого гена-кандидата мы считаем:
   * **+1 балл** за каждое совпадение симптомов гена с симптомами пациента.
   * **-0.5 балла** (штраф) за совпадение с симптомами, которые у пациента *исключены* (excluded=true).
4. **Визуализация (Streamlit):** Интерактивный интерфейс для врача, где можно загрузить данные и увидеть результаты. *(Будет добавлено позже)*.

## Установка и запуск

### Требования
* Python 3.12+
* Conda (рекомендуется)

### Шаг 1: Клонирование репозитория
```bash
git clone [ссылка на репозиторий]
cd genomic-detective
```

### Шаг 2: Настройка окружения
```
conda env create -f environment.yml
conda activate genomic-detective
```

### Шаг 3: Подготовка данных
```
wget -P data/ http://purl.obolibrary.org/obo/hp/hpoa/genes_to_phenotype.txt
```

### Шаг 4: Запуск пайплайна
1. Аннотация вариантов (генерация case_01_annotated.tsv):
```
python src/annotate_case.py
```

2.Запуск скоринга и вывод топ-5 генов:
```
python src/scorer.py
```
