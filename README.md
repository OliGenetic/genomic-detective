## О проекте
Наш пайплайн состоит из четырех последовательных этапов, реализованных в виде независимых модулей:

1. **Парсинг данных (Loader & Parser):**
   * `src/loader.py` — читает таблицы с вариантами (TSV).
   * `src/phenotype_parser.py` — извлекает симптомы пациента. Важная особенность: мы разделяем симптомы на **положительные** (есть у пациента) и **исключенные** (excluded=true, отсутствуют у пациента).

2. **Функциональная аннотация (VEP Annotator):**
   * `src/annotate_case.py` — использует REST API **Ensembl VEP** (GRCh38) для определения гена и типа мутации (consequence) по координатам.
   * Запросы отправляются батчами по 100 вариантов. Если VEP «теряет» вариант, скрипт делает индивидуальный запрос (механизм «спасательного круга»).

3. **Клиническая валидация (ClinVar API):**
   * Мы напрямую обращаемся к официальной базе **NCBI ClinVar** через E-utilities. Если вариант помечен как `Pathogenic`, система добавляет к его баллу весомый бонус (+5.0).

4. **Скоринг и ранжирование (Scorer):**
   * `src/scorer.py` — использует базу знаний **HPO** (`genes_to_phenotype.txt`).
   * **Формула:** `(Совпадения_симптомов * 1.5) + Бонус_за_мутацию + Бонус_ClinVar - (Штраф_за_исключенные * 0.5)`.
   * Бонус за мутацию: `missense_variant` (+2.0), `frameshift/stop_gained` (+3.0), `intron_variant` (-2.0).

5. **Пакетный запуск и Интерфейс:**
   * `src/run_all_cases.py` — автоматически прогоняет пайплайн для всех кейсов и формирует итоговый файл `predictions.tsv`.
   * `app.py` — интерактивный веб-интерфейс на Streamlit для врачей.

## Установка и запуск

### Требования
* Python 3.12+
* Conda (рекомендуется для работы с `cyvcf2` и `pysam`)

### Шаг 1: Клонирование репозитория
```bash
git clone [ссылка на репозиторий]
cd genomic-detective
```

### Шаг 2: Настройка окружения
```
conda env create -f environment.yml
conda activate genomic-detective
```

### Шаг 3: Подготовка данных
```
wget -P data/ http://purl.obolibrary.org/obo/hp/hpoa/genes_to_phenotype.txt
```

### Шаг 4: Запуск пайплайна
1. Аннотация вариантов (генерация case_01_annotated.tsv):
```
python src/annotate_case.py
```

2. Запуск скоринга и вывод топ-5 генов:
```
python src/scorer.py
```
Для автоматического прогона всех 10 кейсов и генерации predictions.tsv:
```
python src/run_all_cases.py
```
