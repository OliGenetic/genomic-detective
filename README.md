# Поиск генетических причин редких наследственных заболеваний

**Команда:** OMIX
**Хакатон:** Химико-хакатон "Синтез" 2026
**Кейс:** 3. Поиск генетических причин редких наследственных заболеваний

---

## О проекте
Наша система решает задачу поиска молекулярной причины редкого наследственного заболевания. 
На вход система получает клиническое описание пациента в формате Phenopacket (JSON с HPO-терминами) и файл генетических вариантов (VCF или TSV). 
На выходе мы предоставляем ранжированный список генов-кандидатов с полным объяснением, почему система выбрала именно их.

## Архитектура пайплайна
Наш пайплайн состоит из четырех последовательных этапов, реализованных в виде независимых модулей:

1. **Загрузка и парсинг (Loader & Parser):**
   * `src/loader.py` — читает сырые таблицы с вариантами (TSV).
   * `src/phenotype_parser.py` — извлекает симптомы пациента. Важная особенность: мы разделяем симптомы на **положительные** (есть у пациента) и **исключенные** (excluded=true, отсутствуют у пациента), чтобы штрафовать гены за неправильные признаки.

2. **Функциональная аннотация (VEP Annotator):**
   * `src/annotate_case.py` — так как исходные данные не содержат информации о генах, мы используем REST API **Ensembl VEP** (GRCh38). 
   * Запросы отправляются батчами по 200 вариантов для оптимизации времени и предотвращения блокировок со стороны API.

3. **Скоринг и ранжирование (Scorer):**
   * `src/scorer.py` — наш алгоритм использует базу знаний **HPO** (`genes_to_phenotype.txt`).
   * Для каждого гена-кандидата мы считаем:
     * **+1 балл** за каждое совпадение симптомов гена с симптомами пациента.
     * **-0.5 балла** (штраф) за совпадение с симптомами, которые у пациента *исключены*.

4. **Пакетный запуск (Pipeline):**
   * `src/run_all_cases.py` — скрипт, который автоматически прогоняет весь пайплайн для всех 10 кейсов и формирует итоговый файл `predictions.tsv`.

## 🛠 Установка и запуск

### Требования
* Python 3.12+
* Conda (рекомендуется для работы с биоинформатическими библиотеками)

### Шаг 1: Клонирование репозитория
```bash
git clone [ссылка на репозиторий]
cd genomic-detective
```

### Шаг 2: Настройка окружения
```
conda env create -f environment.yml
conda activate genomic-detective
```

### Шаг 3: Подготовка данных
```
wget -P data/ http://purl.obolibrary.org/obo/hp/hpoa/genes_to_phenotype.txt
```

### Шаг 4: Запуск пайплайна
1. Аннотация вариантов (генерация case_01_annotated.tsv):
```
python src/annotate_case.py
```

2. Запуск скоринга и вывод топ-5 генов:
```
python src/scorer.py
```
Для автоматического прогона всех 10 кейсов и генерации predictions.tsv:
```
python src/run_all_cases.py
```
